## 5. How to run things (what bit this session)

- Every rig job detached (`ssh -n -f rome 'setsid nohup ... &'`), preflight first chained with
  `&&` (never piped), and a watcher that reports every end state AND silence. Watchers expire
  after 30 min: re-arm before, and seed them with lines already reported.
- **Watcher traps:** (a) a `pgrep -f "x_[c]hain"` inside an ssh command that also names
  `x_chain.log` matches itself — use a pattern whose literal text is not in the command
  (`"[r]un_chain.sh /home/ronald/bench/<name>"`); (b) long prefills and llama.cpp (CPU-heavy,
  GPUs ~8 % busy) write no log lines for 30-60 min — count GPU busy AND the llama-server log as
  progress.
- **Sequencers:** a waiting bash script keeps executing its OLD text after the file is
  replaced; to change a queued step, kill the sequencer and start a new one. Git merges on the
  rig replace files by new inode, so they are safe under running scripts; editing in place is not.
- **Quality runs:** `franken_quality_chain.sh` arms are `franken`, `qwen38`, `franken-ds4`,
  `deepseek`, `franken-glm`, `glm-llama`; knobs `QE_TEMPERATURE`, `QE_TOP_P` (the gateway
  rejects `seed`), `QE_TAG` (output names), `QE_PARTS` (`mmlu` skips the needle),
  `QE_MMLU_SAMPLE` (a file whose `note` starts `subset:` may hold fewer items). Budget-exhausted
  answers keep a 1 500-character `tail` — read it before calling anything a loop.
- **Per-engine binary variables:** start scripts read `FRANKEN_BIN` (Qwen), `FRANKEN_DS4_BIN`,
  `FRANKEN_GLM_BIN`; a globally exported `FRANKEN_BIN` once started the Qwen engine on the GLM
  file. Check the live server's argv (`ps -eo args | grep openai_server`) for `--max-tokens`: GLM's
  start script had 4096 until 2026-09-25.
- Gitea pushes sometimes hang after the transfer; `git status -sb` tells whether it landed. The
  rig syncs over ssh (`git push rome hot-expert-tier:refs/heads/p0-sync`) independently.
- franken-engine commits are made on the rig and pushed from the Mac as claude-bot through a
  scratch clone of `ssh://rome/home/ronald/src/franken-engine` (credentials:
  `~/.config/git/gitea-credentials`, never the keychain).
